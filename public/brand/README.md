# GEO brand directions

- `geo-wave.svg` — recommended and currently used: a friendly speech-shaped G with a Black Sea wave.
- `geo-pin.svg` — a location-first alternative using the Georgian flag cross.
- `geo-sun.svg` — a warmer Batumi sunrise and sea alternative.

All three are original SVG marks created for GEO. They are compact, high-contrast, and remain legible as PWA icons or small navigation marks.
